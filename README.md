# Student Management UI

React frontend for the Student Management System.

## Tech Stack
- React 18 (Vite)
- React Router DOM
- Axios
- Tailwind CSS

## Features
- View all students with pagination
- Add new student with form validation
- View individual student details
- Delete students
- Fully connected to Spring Boot REST API

## How to Run
1. Make sure the Spring Boot API is running on port 8081
2. Clone this repo
3. Run: npm install
4. Run: npm run dev
5. Open http://localhost:5173
